# Password Strength Checker

## What This Does
Checks how secure a password is. Scores it based on length, uppercase, lowercase, numbers, and special characters.

## Live Demo
**Try it instantly:** [Click here to run on OnlineGDB](https://onlinegdb.com/seCzXdH6u)

Just click Run and type any password.

## How It Works
1. Enter any password
2. Program checks:
   - Length (6, 8, or 12+ chars)
   - Has uppercase letters
   - Has lowercase letters  
   - Has numbers
   - Has special chars (!@#$%)
3. Gets score from 0-12
4. Shows WEAK / MEDIUM / STRONG

## Scoring System
| Factor | Points |
| :--- | :--- |
| 6-7 chars | +1 |
| 8-11 chars | +2 |
| 12+ chars | +3 |
| Has uppercase | +2 |
| Has lowercase | +2 |
| Has numbers | +2 |
| Has special chars | +3 |
